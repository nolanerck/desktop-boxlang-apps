Electron in 3 Parts
Renderer
Main
Preload

Renderer
Front-end
HTML, JavaScript, CSS
Stuff that shows up in the UI
Your "view" layer"
Can install any JS
npm install just like always

Main
Back-end
Node.js (and BoxLang)
Server-side, OS, System calls, File I/O, eco
Your "model" and "service" stuff
Can install ANY Node.js packages
npm install just like always

Preload
Connect back-end to front-end
Your "controller" layer

Can use any JavaScript stuff
Vanilla JS
Web Components
Vue.js
React
etc
