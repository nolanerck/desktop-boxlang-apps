What is Electron?

  • Make desktop apps w/ HTML & JavaScript
  • Windows and Mac, not mobile
  • ala PhoneGap / Ionic, but for desktop
  • Node.js support built-in
  • Chromium browser

Getting Started

  • npm install electron --save-dev

Electron in 3 Parts

  • Renderer
  • Main
  • Preload

Renderer

  • Front-end
  • HTML, JavaScript, CSS
  • Stuff that shows up in the UI
  • Your "view" layer"
  • Can install any JS
  • npm install just like always

Main

  • Back-end
  • Node.js (and / or BoxLang)
  • Server-side, OS, System calls, File IO, etc
  • Your "model" and "service" stuff
  • Can install any Node.js packages
  • npm install just like always

Preload

  • Connect back-end to front-end
  • Your "controller" layer, sort of
  • For passing Node to the front-end
  • Optional w/ BoxLang but:
    try to use good OOP design

Use Any JavaScript Stuff

  • Vanilla JS
  • Web Components
  • Vue.js, React, etc
    (build steps are needed)

Building The App

  • npm install @electron/packager
    or npm install electron-forge
  • packageer - more "lightweight"
  • elecron-forge - more features for updatng, builds, publishing, etc
    ...but makes larger binaries, can be slower

Building The App

  • npm run package-mac
  • npm run package-win
  • Can make both Windows and Mac intel binaries on a Mac machine!

Selling Your App

App Signing

App Signing

  • Required for Apple and MicroSoft Stores
  • Optional for downloads on your website
    but...

App Signing - Apple

  • Pretty easy
  • Make Apple Developer Account
  • developer.apple.com
  • Download XCode
    (If it fails, reboot, wait a day, try again)

App Signing - Microsoft

  • Extremely Painful!
  • 3rd Party Cert
    • DigiCert, GlobalSign, a few others
    • ~$30 to $100 monthly
  • Azure Key Signing (new)
    • Cheaper, but if you've been in business 3+ years
  • Must store in encrypted key store
  • Budget 2 - 4 weeks
